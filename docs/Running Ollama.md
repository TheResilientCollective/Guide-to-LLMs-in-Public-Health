# Running Ollama

This document handles:

- If running on a cloud server
  You should already have a server that you can connect to with a terminal window.

- If running on a self hosted server
  You should already have a server that you can connect to with a terminal window.

- If running on a laptop / personal computer

---

> The general idea is you will have an LLM running on your computer.
> It will only be able to do what the logged in user has permission to do - and the user will be responsible for its actions.
> You will then connect that LLM to some tools to help it do things (e.g. edit a word document). That list of tools can change over time very easily.
