# Hosting a Server in the Cloud

You have a cloud service provider (AWS, GCP, ...) and you will need to create a server that runs on that cloud environment. The following is a guide to getting a server up and running. If you reached here through the Decision Tree, keep in mind the decision points you reached along the way.

Spinning up a server

- naming it
- provisioning CPU, RAM, and GPU
- Networking
- Access (SSH keys)
- DNS and HTTPS

Accessing your server

- SSH
